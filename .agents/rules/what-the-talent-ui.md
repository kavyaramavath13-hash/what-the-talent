# What The Talent! — UI Rules

1. Light Butter `#FFF3A6` is the dominant background.
2. Rust `#BA3801` and Navy `#4A69B3` are the core brand colors.
3. Do not introduce unrelated colors or generic AI gradients.
4. Main title and major headings use an Obviously-style bold display treatment.
5. English tagline uses an elegant editorial/Trovical-Calm-Free-style treatment.
6. Telugu tagline is bold and rust.
7. Preserve the editorial/wireframe aesthetic: organic shapes, irregular outlines, layered blocks, asymmetry, strong typography, and generous spacing.
8. Cards must look designed, not like generic SaaS cards.
9. The Explore experience is Category → Talent Type → Artist → Profile.
10. Artist cards must show photo, name, location, experience, hired count, View Details, and Book Now.
11. Artist profile must include image, name, experience, contact, portfolio, location, Book Now, and Chat Now.
12. Keep the navbar structure consistent: logo left, Home/About/Explore/Gallery/Talent centered, Sign In right.
13. Use subtle motion and respect prefers-reduced-motion.
14. Always design mobile intentionally rather than merely shrinking desktop.
15. Keep accessibility, keyboard navigation, focus states, semantic HTML, and readable contrast.
