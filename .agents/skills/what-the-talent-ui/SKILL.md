# What The Talent! UI Skill

When modifying this project, treat PROMPT.md as the product specification and `.agents/rules/what-the-talent-ui.md` as the non-negotiable visual rules.

Before changing a page:
- inspect the existing component structure
- reuse existing components where possible
- preserve the brand palette and typography
- preserve responsive behavior
- avoid introducing a second visual language

When adding Explore functionality, preserve the state flow:
category -> talent type -> artist cards -> artist profile.

When adding artist data, include name, category, talent type, location, experience, hired count, bio, contact/availability, and portfolio items.

When testing, verify desktop and mobile layouts and all major interactions.
