# What The Talent! — Antigravity Workspace Starter

This folder contains the master prompt and Antigravity workspace instructions for building the complete **What The Talent!** website.

## How to use

1. Open this folder as your Antigravity workspace, or copy the `.agents` folder into your existing website project.
2. Open `PROMPT.md`.
3. Paste the full contents of `PROMPT.md` into Antigravity Agent/Claude Sonnet.
4. Tell the agent to implement the complete website in the current workspace.
5. Add your logo and talent/category images under `public/references/` when ready.

The `.agents/rules/` and `.agents/skills/` files provide persistent project guidance so later edits keep the same visual system.
